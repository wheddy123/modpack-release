# ThacLoan Server Modpack 1.21.1 — 80 mods

**NeoForge 21.1.235 | Create 6.0.10 | Ars Nouveau 5.12.1**

## Installation
1. Install **NeoForge 21.1.235** for Minecraft 1.21.1
2. Copy all `.jar` files from `mods/` into your client `mods/` folder
3. Delete old mods not in the list
